# 03-react-movies

## Завдання

Створи веб-додаток на React для пошуку та перегляду інформації про фільми.

### Мета

Реалізувати інтерфейс, в якому користувач може:

- шукати фільми за назвою;
- переглядати список результатів;
- відкривати детальну інформацію про конкретний фільм;
- додавати фільми до улюблених;
- працювати з адаптивним інтерфейсом.

### Технічні вимоги

- Використай React + Vite.
- Створи компонентну структуру: header, search, movie list, movie card, details view, favorites.
- Отримуй дані з API, наприклад OMDb API або іншого відкритого джерела.
- Додай стан завантаження, помилки та пустий результат.
- Використай localStorage для збереження улюблених фільмів.
- Зроби інтерфейс адаптивним для мобільних та десктопних пристроїв.

### Функціонал

1. Пошук фільмів
   - поле вводу для назви;
   - кнопка пошуку;
   - пошук за натисканням Enter.

2. Список фільмів
   - відображення карток фільмів;
   - коротка інформація: постер, назва, рік, жанр, рейтинг.

3. Деталі фільму
   - при кліку на картку відкривається модальне вікно або окрема сторінка;
   - показати опис, жанр, режисера, тривалість, рейтинг, акторів.

4. Улюблені
   - кнопка "Add to favorites" / "Remove from favorites";
   - відображення окремого розділу з улюбленими фільмами.

5. UX
   - skeleton/loading state або спіннер;
   - повідомлення про помилку, якщо запит не вдався;
   - при відсутності результатів показувати відповідне повідомлення.

### Критерії оцінювання

- коректна робота пошуку;
- якісна структура компонентів;
- чистий і зрозумілий React-код;
- адаптивний дизайн;
- робота з асинхронними запитами;
- збереження стану улюблених фільмів.

### Додаткові завдання

- реалізувати фільтрацію за жанром або рейтингом;
- додати пагінацію або infinite scroll;
- використовувати React Router для окремих сторінок фільмів;
- зробити красиву темну тему.

### Рекомендації

- спочатку створіть базову структуру проекту;
- відокремте логіку роботи з API в окремий сервіс або хук;
- не забувайте про обробку помилок та станів завантаження;
- перевіряйте UI на мобільних розмірах.

### Оцінка

Проєкт оцінюється за якістю реалізації, читабельністю коду, функціональністю та зовнішнім виглядом.
